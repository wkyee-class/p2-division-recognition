# 除法的認識

小二除法的認識課堂遊戲（分物與除式）

網站發布後，請用 GitHub Pages 網址開啟：
https://wkyee-class.github.io/p2-division-recognition/

## 怎樣用

- 學生與老師用同一個網站。首頁有「學生」和「老師」兩個按鈕。
- 學生：點選自己的學號（1–40），再輸入老師顯示的四位課堂編號，然後按題意畫環線分物，填寫橫式和直式，再按「提交」。課堂上不會顯示對錯或正確算式。網絡不穩時可選「單機練習／自己溫習」。
- 老師：登入後建立或重開課堂，把課堂編號投影給學生。控制台可看誰在線、誰已提交、做到第幾題，亦可點開作品、廣播討論、控制下一題、開新一輪和匯出資料。老師入口也可開啟：https://wkyee-class.github.io/p2-division-recognition/teacher.html

這是與「乘和除的關係」分開的另一個課堂遊戲。
